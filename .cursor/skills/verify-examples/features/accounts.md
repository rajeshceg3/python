# Account automation

## Sub-features

`tweet_selenium.py and whatsapp_selenium.py`

## How to get to it (user POV)

Open the named example and use its documented source inputs. These are independent scripts, not app routes.

## Driving it with Python

Source syntax only. Full browser workflow may log in and send/post messages, so obtain explicit test recipient/content scope and isolated account before driving.

## Gotchas

Current verification authority does not authorize actual messaging/posting. Do not run top-level automation or use saved account cookies.
