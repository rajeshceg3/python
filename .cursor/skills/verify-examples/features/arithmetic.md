# Arithmetic

## Sub-features

`pytest/sumproduct.py and pytest/test_sumproduct.py`

## How to get to it (user POV)

Open the named example and use its documented source inputs. These are independent scripts, not app routes.

## Driving it with Python

Helper executes actual function for positive/zero/negative/fractional inputs and invokes shipped test_sumproduct.

## Gotchas

No standalone CLI exists. Do not confuse the source pytest directory with installed pytest.
